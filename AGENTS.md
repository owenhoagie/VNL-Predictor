# Agent Guidance

## Version control

Version control is highly prioritized in this repository.

- Inspect Git status and the active diff before making or publishing changes.
- Preserve existing history and never discard user-owned work.
- Keep commits intentional, cohesive, and in a verified working state.
- Use descriptive branches and commit messages that clearly communicate scope.
- Run the relevant checks before committing and pushing.
- Keep generated artifacts synchronized with the source data and models they represent.
- Report the branch, commit, validation status, and remote publication result after publishing.
